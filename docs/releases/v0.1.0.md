# base-agent-0.6b v0.1.0

**Released 2026-11-16. The first release.** base-agent-0.6b packs the Orama base model, a fine-tune
of Qwen3-0.6B, into a container image that the Orama operator copies onto every workspace Zetta's
volume, so a native agent created without a model runs on it. Because it is the first release, this
page lists everything in it.

## What it includes

### The image: `oramasearch/base-agent-0.6b:v0.1.0`

- **The checkpoint `v16`** of the Hugging Face model `OramaSearch/base-agent-0.6b`, at Hub revision
  `3f6eb0850f3c9ed1743c56b9aff80ba8ddb73084`, under `/model/`: `config.json`,
  `generation_config.json`, `model.safetensors` (fp32, 2,384,234,937 bytes), `tokenizer.json`,
  `tokenizer_config.json`, `vocab.json`, `merges.txt` and the version's `README.md`.
- **`/bin/sh`** from BusyBox 1.37, the base image, pinned by its multi-platform index digest
  (`sha256:a7dbc319…`), because the operator's copy script runs in this image (#5).
- Every file readable by uid 10001, the Zetta node's user; the image runs as that user.
- **A build-time check**: the build fails unless `/model` holds the config, the weights and a
  tokenizer the engine can load.
- Built for `linux/amd64`, from the tag, with BuildKit.

### The repository

- The `Dockerfile` and the contract in `README.md`: what `/model` holds, the shell, the user, and
  the rule that a published tag is never moved.
- The build recipe: a context directory with one folder, `checkpoint/`, taken from a local
  checkpoint or downloaded from the Hub.
- `VERSION` holds the release version; `tools/test-version.py` checks that these notes exist, are
  indexed and are named in the README.

## What it does not include

- **No `v16` image tag.** The operator's default base model image names
  `oramasearch/base-agent-0.6b:v16`, which is not pushed by this release (#6). The release image is
  tagged `v0.1.0`.
- **No bf16 image.** The checkpoint is fp32 (about 2.4 GB); a bf16 copy would halve the image and
  the volume cost.
- **Checkpoint pinning and checksums in the build** are not included: #4 (pin the Hub revision and
  verify the files' checksums) is deferred, because it changes the build's inputs. This release
  records the revision and the weights' checksum below instead.
- **No `linux/arm64` image.**

## Known issues

- **BusyBox (GPL-2.0) is the image's base** (#10). The image carries BusyBox unmodified, and its
  source is at https://busybox.net/downloads/busybox-1.37.0.tar.bz2. Whether a written source offer
  must accompany the image, or the image moves to `scratch` with static binaries, is open.
- **The training corpus** (#9): the weights were fine-tuned on a synthetic corpus partly produced
  with a hosted model, and the corpus and the Hugging Face model card are still to be cleaned before
  they are published. The Hugging Face repository `OramaSearch/base-agent-0.6b` is not public yet.
- **The legal review of the weights' licence** decided in #7 is open.
- **The checkpoint is a bootstrap, not a production model.** The `v16` folder's own README, in the
  image at `/model/README.md`, says so: it can fabricate claims and confuse a clarifying question
  with an action. It is the starting point for reinforcement training.
